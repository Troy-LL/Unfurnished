# /voice

Set the writing register for this chat only. A new chat starts at default.

- `/voice` — report the current register and the one-line meaning of each
- `/voice plain` — whiteboard teammate. Contractions and hedges are in-bounds. Kill leverage / utilize / robust / seamlessly. No 20-word cap. Not a Boeing manual.
- `/voice ste` — controlled docs. Procedural ≤20 words, one instruction, condition before command. Descriptive ≤25. Simple tenses. No should/would/may/might. Active voice. Code stays exact. Refuse marketing; offer `/voice plain`.
- `/voice off` — drop the register.

Do not treat this as always-on. Do not load SimpleEnglish or any marketplace skill.
